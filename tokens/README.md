# Design tokens

Figma variable exports live in subfolders by collection:

| Folder | Contents |
|--------|----------|
| [`figma/`](figma/) | Semantic, primitive, and brand tokens |
| [`figma/brand/`](figma/brand/) | 10 brand mode palettes (`default`, `sakura`, `soft-sky`, …) |
| [`figma/breakpoint/`](figma/breakpoint/) | Responsive breakpoints (`xs`–`2xl`) |

See [`figma/README.md`](figma/README.md) for import and sync instructions.
