7 · Modal & popup catalog

Every popup with its trigger and lifecycle.

PopupTriggerLifecycle
BodyRecordPopup
= DrawingCanvasPopup		 "บันทึกร่างกาย" in Treatment Step 3 Save gated by dirty flag (any mark/draw/note/erase enables it) → bubbles onSave(markers) then close
VitalsSignGraphDialog Vitals header in OPD Step 1 / Treatment Step 2 View-only chart → close
ScreeningConfirmPopup Final save in /opd/screening Confirm → return to /opd/queue
BedSelectionPopup Bed selector in Screening Step 4 Pick → return value, close
UnsavedChangesPopup Navigate away from a dirty multi-step form Save · Discard · Cancel
DeleteQueueConfirmPopup Trash icon on any queue row Confirm → row removed
AlertDialog Generic confirmation / error OK · Cancel
ProfilePopover User card in sidebar Opens SettingsModal
SettingsModal "Theme" in ProfilePopover Light / dark / system + 10 brand colors
