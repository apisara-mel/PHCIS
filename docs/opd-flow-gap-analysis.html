🎨 Legend

Full — ≥ 80% ของ flow ขั้นนั้นทำได้ครบ Partial — มีบางส่วน แต่ขาด feature สำคัญ Missing — ยังไม่มี / stub menu เท่านั้น

Priority badges: P1 Critical ขัด workflow / P2 Important ทำให้ครบวงจร / P3 Nice-to-have เสริม

0
กดบัตรคิว (Kiosk / Self-Service Entry) Missing · 0%
Flow: ผู้รับบริการมาถึง → ตรวจสอบสิทธิ → รับบัตรคิว → ออก e-Receipt
PHCIS: ไม่มี route — walk-in/appointment branch ไม่ปรากฏ → เข้า /registration ตรงๆ
ขาด:
  • Route /kiosk + 2-branch UI (walk-in / มาตามนัด)
  • Hardware integration: card reader, camera, EDC, QR payment
  • Online rights check (สปสช.) ที่ kiosk
  • e-Receipt printing
1
ลงทะเบียนรับบริการ (OPD 1.2.1) Full · 90%
Flow: ลงทะเบียน Walk-in/นัด → เปิด Visit Number (1.1.2.1) → ออกคิวตาม Slot
PHCIS: /registration/queue + /registration/register (5 steps: Personal · Address · Contact · Rights · Flags)
ขาด:
  • VN (Visit Number) generation — ปัจจุบันใช้แค่ queue + hn ไม่มี VN ที่ link visit episodes (1.1.2.1)
  • Time-slot scheduling UI สำหรับนัดล่วงหน้า
2
คัดกรอง + ซักประวัติ (OPD 1.2.2) Full · 95%
Flow: Vital signs · BMI · Pain · ESI · อาการนำ · แพ้ยา · โรคประจำตัว · พฤติกรรมสุขภาพ
PHCIS: /opd/screening 5 steps: Vitals · Chief Complaint+Pain+Triage · Allergies · Chronic · Forms picker
เสริมได้:
  • ESI level visual indicator (สี + label "Resuscitation / Emergency / Urgency / Semi-Urgency / Non-Urgency")
  • พฤติกรรมสุขภาพ (สูบบุหรี่ / ดื่มแอลกอฮอล์) — ตอนนี้อยู่ใน Forms Library ไม่ใช่ในตัว screening
3
จัดการคิวและรอพบแพทย์ (1.3) Full · 100%
Flow: รายชื่อ + สถานะ + ลำดับคิวตามแพทย์/คลินิก
PHCIS: /opd/queue, /treat/queue + QueueSubMenu sub-section
ครบถ้วน — pagination 20/page, sort, filter chips, status badges
4
แพทย์ตรวจรักษา — EMR + CPOE (1.4 + 1.5) Partial · 70%
Flow: Timeline · CC · Physical Exam · Diagnosis · Med Rec · Notes · Allergy · Attachments · Telemed + CPOE: medication/lab/x-ray/procedure/consult + CDSS + Order Set + e-Refer
PHCIS: /treat/record 7 steps · BodyDrawingCanvas สำหรับ Physical Exam · ICD-10 AISearch · cross-class allergy panel
ขาด:
  • SOAP Progress Note — ตอนนี้มีแค่ free-text (nurseExam / doctorExam / diagnosisNote)
  • Medication Reconciliation — ไม่มี panel ที่ reconcile ยาเก่า ↔ ใหม่
  • Order Set — FrequentOrdersCard เป็น chip-recall เฉยๆ ไม่ใช่ bundled order set
  • e-Refer — ส่งต่อนอกสถานพยาบาล (consult tab ใน Step 5 เป็น internal เท่านั้น)
  • SNOMED-CT coding — มีแค่ ICD-10
  • Full CDSS — มีแต่ allergy panel; ขาด Dose limit · Drug Interaction · Drug Duplicate · configurable thresholds
5
ตรวจสอบสิทธิและค่าใช้จ่าย (1.7) Missing · 10%
Flow: เรียกดูสิทธิการรักษา (สปสช., กทม.) + คำนวณส่วนเกิน / ร่วมจ่าย
PHCIS: มี rightsGroups ใน Registration Step 4 (SSO/Gold/CSMBS/Other) แต่ไม่มี cost calc page
ขาด:
  • Route /finance/lookup + online สปสช./กทม. API call
  • Cost breakdown UI (services + meds + labs + imaging)
  • Claim eligibility logic ต่อ rightsGroup
  • Copay / surplus calculation
Reference: product-spec §10.4 "finance" stub
6
จ่ายยาและคำแนะนำ — เภสัชกรรม (1.9) Missing · 10%
Flow: ตรวจใบสั่งยา · จ่ายยา · พิมพ์ฉลาก · counseling · บันทึก dispensing
PHCIS: medicationCatalog.js (~50 drugs) มีอยู่แล้ว · pharmacy menu เป็น stub
ขาด:
  • Route /pharmacy/queue + dispense workflow
  • "เรียกคิว" — counter call functionality
  • Label printing template
  • Allergy double-check (re-validate against patient drugAllergies)
  • Inventory deduction tracking
  • Write-back dispensed status → TreatmentVisit
Reference: product-spec §10.3 "pharmacy" stub
7
ชำระเงิน (1.8) Missing · 0%
Flow: เงินสด · บัตรเครดิต · QR Code → ออก e-Receipt + ส่วนลด/ยกเว้น → ปิดสิทธิ
PHCIS: ไม่มี — finance stub
ขาด:
  • Route /finance/payment + payment method picker
  • Kiosk QR scan integration (เชื่อมกับ Step 0)
  • e-Receipt generation + print/save PDF
  • Discount / waiver tracking
  • "ปิดสิทธิ" — close-visit state machine
8
จำหน่ายผู้รับบริการ (OPD 1.2.6) Missing · 5%
Flow: ส่งกลับบ้าน / ส่งต่อแผนกอื่น / ส่งต่อสถานพยาบาลอื่น (e-Referral)
PHCIS: หลัง save Treatment Step 7 → return ไป queue เฉยๆ ไม่มี discharge state
ขาด:
  • Discharge popup ตอน final save พร้อม 3 buttons: กลับบ้าน / ส่งต่อแผนกอื่น / Admit IPD
  • e-Referral integration (เชื่อม สปสช. / Health Link)
  • Observation/Admission state flow
9
บันทึกนัดหมาย (1.6) Full · 80%
Flow: เลือกคลินิก/แพทย์/วันเวลา → พิมพ์ใบนัด → แจ้งเตือนผ่าน Mobile
PHCIS: /treat/record Step 6 (mode skip/schedule · ApptCollapse · clinic/type/doctor/reason/preparation · advance-orders · onsite/telemedicine · date + APPT_TIMESLOTS)
ขาด:
  • Print appointment slip template
  • SMS / LINE notification integration
  • Master scheduling — ปัจจุบัน per-record; appoint menu (stub) ควรเป็น master calendar

📈 Reporting

ระบบรายงานอ้างอิงจาก flow — สรุปรายงานเบิกจ่ายชดเชย, top-tests-ordered, etc.

PHCIS: /dashboard 6 KPIs + 13 charts — ครอบคลุม basic reporting แล้ว แต่ขาด:

  • เบิกจ่ายชดเชย report (อ้างอิง flow's "ส่งเบิกจ่ายชดเชย")
  • Drill-down per-clinic / per-doctor / per-rights-group
  • Export CSV / PDF
  • Date-range comparison (vs previous period)
